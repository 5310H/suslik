# Frigate + Suslik Test

An experimental **combined Frigate build**, with Suslik-derived temporal face
confirmation and cross-camera visits inside Frigate's backend and UI.

This is separate from the standalone Suslik add-on. It is based on Frigate
0.18.2, supports amd64 and USB Coral passthrough, and starts with no cameras.

Use [the installation and test guide](DOCS.md). No existing Frigate settings or
media are imported automatically. Recognition accuracy, real CPU savings and
hardware behavior still need testing on your HAOS system.
