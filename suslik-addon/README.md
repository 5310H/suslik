# Suslik for Home Assistant OS

Runs the existing Suslik CPU release as a native Supervisor add-on. Suslik
recognizes people in Frigate recordings and groups visits across cameras.

Experimental; **amd64 only**. No GPU passthrough or Ingress in this release.
The application and models are reused from an immutable upstream image.
See [installation and operation](DOCS.md) and
[architecture and validation limits](../docs/HAOS-ARCHITECTURE.md).

Model licensing remains as described in the repository's NOTICE.
